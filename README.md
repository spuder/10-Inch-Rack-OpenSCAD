## 📝 Description

Opescad files that can be used to make(3D Print) a whole 10in server rack from frame to mounts. Also some options for 6in racks.

## ⚡ Quick Start

```bash

# 1. Clone the repository
git clone https://github.com/0310njs/Server-Rack-Generator-Openscad/tree/Stans-Branch.git

# See the Development Setup section below
```

## 🚀 Available Scripts

- **all** — `make all`
- **test** — `make test`
- **test** — `make test`
- **test-stl** — `make test-stl`
- **test-all** — `make test-all`
- **preview** — `make preview`
- **clean** — `make clean`
